# 📊 Projeto Excel — Organizador de Dados para Declaração do Imposto de Renda

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio prático da **DIO (Digital Innovation One)**, no curso **Santander — Excel com IA e Claude**, com orientação do especialista **Felipe Aguiar**.

O objetivo foi desenvolver uma planilha no Microsoft Excel para organizar informações e documentos necessários à preparação da declaração do Imposto de Renda de Pessoa Física (IRPF), facilitando o preenchimento, a consulta e o acompanhamento dos dados financeiros.

## 🎯 Objetivos

- Organizar os dados pessoais do titular.
- Centralizar informações sobre rendimentos e valores bancários.
- Registrar entradas financeiras mensais.
- Facilitar a organização de documentos e comprovantes.
- Utilizar fórmulas do Excel para automatizar cálculos.

## ⚙️ Funcionalidades

A planilha está organizada em quatro abas principais:

### 1. Dados do titular
Área destinada ao cadastro das informações pessoais, como nome, CPF, data de nascimento, endereço, contatos e outras informações relevantes para a declaração.

### 2. Informes de rendimentos bancários
Permite registrar informações de diferentes instituições financeiras, incluindo banco, valores atuais e identificação dos documentos anexos.

A planilha também possui um cálculo automático para somar os valores informados nos registros bancários.

### 3. Notas bancárias e extratos de holerites
Área destinada ao registro de entradas financeiras, com campos para data, categoria e valor, auxiliando na organização dos rendimentos ao longo do tempo.

### 4. Lista de bancos
Contém uma lista de instituições financeiras para apoiar o preenchimento padronizado dos dados bancários.

## 🛠️ Ferramentas utilizadas

- **Microsoft Excel:** criação e organização da planilha.
- **Fórmulas do Excel:** automatização de cálculos e totalização de valores.
- **Inteligência Artificial:** contexto de aprendizagem do curso sobre Excel com IA e Claude.

## 📚 Aprendizados

Com o desenvolvimento deste projeto, foi possível praticar conhecimentos relacionados a:

- Organização e estruturação de dados em planilhas.
- Utilização de fórmulas para automatizar cálculos.
- Centralização de informações financeiras.
- Estruturação de campos para facilitar o preenchimento.
- Aplicação do Excel na resolução de problemas práticos.

## 🚀 Como utilizar

1. Baixe o arquivo `DIO - Taxes.xlsx` disponível neste repositório.
2. Abra a planilha no Microsoft Excel.
3. Acesse as abas e preencha os campos com as informações correspondentes.
4. Confira os valores registrados e os totais calculados automaticamente.
5. Organize os documentos comprobatórios necessários para a preparação da declaração.

**Importante:** esta planilha é uma ferramenta de organização e não substitui o programa oficial da Receita Federal, a orientação de um profissional contábil ou a conferência das regras vigentes do Imposto de Renda.
